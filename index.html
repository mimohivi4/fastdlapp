Frequently asked questions

Everything you need to know about using Adawati tools

Are all tools really free with no signup?

Yes. Every calculator, converter and game on Adawati is 100% free, unlimited, and requires no account. Most tools run entirely in your browser, so your data never leaves your device.

Which tool should expats in Oman use first?

Start with the Salary Calculator (SPF deduction), End-of-Service gratuity, OMR currency converters (INR, PKR, BDT, EGP, PHP), VAT 5% calculator, and the Oman salary, labour-law and cost-of-living guides.

Do the developer tools send my code to a server?

No. JSON Formatter, Base64 Encoder, Color Converter and Text Case Converter all process data locally with JavaScript. Nothing is uploaded — safe for API keys and private snippets (though you should still avoid pasting production secrets).

Can I use Adawati offline or install it as an app?

Yes. Adawati is a PWA: after your first visit, core tools are cached and work offline. On Chrome/Edge/Safari choose “Add to Home Screen” / “Install” to get an app-like experience.
